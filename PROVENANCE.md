# Provenance

The interface moved here from `nodestro-api` (NAL-C2). The first commit of `src/` holds the files of
`nodestro-api/src/nodestro_api/webui/` at commit `e8c84c4d5f084154cdf9eb33d2a1c412f7261305` (2026-11-15) unchanged:
`index.html`, `app.js`, `app.css`, `markdown.js`, `i18n/*.json`, `brand/*.png`. Their earlier history stays in
`nodestro-api` (`git log -- src/nodestro_api/webui`).

From then on the files change only here; `nodestro-api` embeds a copy of a given commit (`scripts/vendor_app_ui.py`
there, recorded in `src/nodestro_api/webui/VENDORED.md`).
